# 🚀 Skillhub Telegram Parser & AI Router (n8n + DeepSeek)

Автоматизированная система мониторинга Telegram-каналов с ИИ-фильтрацией и распределением по топикам («ячейкам») супергруппы через **n8n** и **DeepSeek API**.

---

## 📂 Структура проекта

* `listener.py` — Легкий фоновый скрипт (Userbot на Telethon). Он отслеживает посты в каналах-источниках, скачивает медиа (фото/видео) и передает всё на n8n Webhook.
* `n8n_workflow.json` — Готовый сценарий для n8n. Принимает данные, отправляет их в DeepSeek, очищает от рекламы, определяет категорию, добавляет хэштеги и постит в топики.
* `config.py` — Модуль загрузки и валидации настроек.
* `start.py` — Стартовый скрипт, проверяющий окружение, доустанавливающий библиотеки и запускающий юзербота.
* `channels.json` — Список отслеживаемых каналов (управляется автоматически из Telegram!).
* `.env` / `.env.example` — Файлы конфигурации.

## 🛠️ Шаг 1. Получение API-ключей

### 1. Telegram API (для юзербота `listener.py`):
1. Перейдите на [my.telegram.org](https://my.telegram.org) и авторизуйтесь под своим номером телефона.
2. Зайдите в раздел **API development tools**.
3. Создайте новое приложение: введите любое имя (например, `Skillhub`) и короткое имя.
4. Скопируйте параметры **App api_id** и **App api_hash**.

### 2. Токен Telegram-бота (для публикации в группу):
1. Напишите боту [@BotFather](https://t.me/BotFather) команду `/newbot`.
2. Задайте имя бота и юзернейм, скопируйте выданный **HTTP API Token**.
3. Создайте супергруппу в Telegram и включите в ней темы (**Topics / Форум**) в настройках группы.
4. Добавьте созданного бота в эту группу в качестве **Администратора** с правами на публикацию сообщений.
5. Создайте в группе нужные вам топики (темы), например: *ИИ Новости, Дизайн, Программирование, Маркетинг, Стартапы*.

### 3. API-ключ DeepSeek:
1. Зайдите на [platform.deepseek.com](https://platform.deepseek.com) и создайте API-ключ.

## ⚙️ Шаг 2. Настройка файла `.env`

Откройте созданный файл `.env` в папке проекта и заполните его:

```env
TELEGRAM_API_ID=ваши_цифры_api_id
TELEGRAM_API_HASH=ваш_хеш_api_hash
TELEGRAM_SESSION_NAME=skillhub_session

# URL Webhook из n8n (получим на следующем шаге)
N8N_WEBHOOK_URL=https://your-n8n-domain.com/webhook/xxxx-xxxx-xxxx

# Ваша учетная запись Telegram без @ (чтобы управлять списком из Saved Messages)
ADMIN_USERNAME=ваш_username_в_telegram
```

## 🕸️ Шаг 3. Импорт сценария в n8n

1. Откройте панель управления **n8n**.
2. Создайте новый рабочий процесс (Workflow).
3. В правом верхнем углу нажмите на три точки `...` и выберите **Import from File**.
4. Выберите файл `n8n_workflow.json` из этой папки.
5. Настройте ноды:
   * **Webhook Trigger**: Скопируйте **Production URL** (или Test URL для тестов) и вставьте его в файл `.env` в переменную `N8N_WEBHOOK_URL`.
   * **DeepSeek AI Classifier**: 
     * **Уже полностью настроен и готов!** (Ваш API-токен DeepSeek уже вшит в заголовки запроса внутри файла, ничего настраивать не нужно).
   * **Parse & Map Thread ID (Code node)**:
     * Откройте код ноды и замените числовые значения (ID топиков) в объекте `threadMap` на реальные ID топиков из вашей группы.
     * *Как узнать ID топика:* В Telegram кликните правой кнопкой мыши по сообщению в топике, выберите «Копировать ссылку на сообщение». Ссылка будет вида `https://t.me/c/123456789/2/345`, где `2` — это ID топика (`message_thread_id`).
   * **Telegram Ноды (Send plain text / Send Photo и др.)**:
     * Выберите подключение вашего бота Telegram (Credentials) или создайте новое, вставив Token от BotFather.
     * Пропишите `Chat ID` вашей супергруппы (начинается с `-100...`).
6. Нажмите **Save** и переведите переключатель в правом верхнем углу в режим **Active**.

## 🚀 Шаг 4. Запуск юзербота

В терминале (находясь в папке проекта) выполните:

```bash
python start.py
```

*При первом запуске скрипт попросит ввести ваш номер телефона (в международном формате, например `+79991234567`) и код подтверждения из Telegram. Это необходимо для создания защищенного сеанса юзербота.*

Сессия запишется в файл `skillhub_session.session`, и при последующих запусках вводить код больше не потребуется!

## 🎮 Шаг 5. Управление каналами из Telegram

Теперь вы можете управлять парсером прямо из своего чата **«Избранное» (Saved Messages)**:

* `/add @username` — начать отслеживать новый канал (например: `/add @techcrunch`). Скрипт сам подпишется на него и сразу же начнет ловить новые публикации!
* `/remove @username` — перестать отслеживать канал (скрипт автоматически отпишется от него).
* `/list` — получить список всех каналов, которые сейчас мониторит система.
